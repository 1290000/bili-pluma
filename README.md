## 它做什么

浏览器里有两个身份，职责完全分开：

| 身份 | 存在形式 | 负责 |
| --- | --- | --- |
| **主账号** | 浏览器自己的登录态，扩展不碰 | 收藏 · 点赞 · 评论 · 投币 · 播放历史 |
| **播放账号**（大会员） | 扩展加密存储的凭据 | 仅提供取流，解锁 4K / 1080P60 / HDR / 杜比 / Hi-Res |

原理是**请求级身份代理**：浏览器全程保持主账号登录，扩展只在白名单取流接口上换一套凭据重发。**不切 cookie、不写 cookie jar、主账号会话从头到尾没被动过。**

所以点赞记在主账号、历史记在主账号、评论是主账号发的——但视频流按播放账号的权限拉。

## 它不做什么

- ❌ 不绕过付费墙（会员专享番剧/电影仍需购买）
- ❌ 不伪装会员标识（界面如实显示真实状态）
- ❌ 不解锁地区限制
- ❌ 不共享账号
- ❌ 不提供任何破解或加密绕过手段

## 音质需要你的环境配合

**Hi-Res** 通常开箱可用（Chrome/Edge 原生 FLAC 解码）。

**杜比全景声** 需三件事同时成立：装 Microsoft EC-3 解码扩展（Store ID `9nvjqjbdkn97`）· 浏览器启用 media foundation playback · 系统音频设为空间音频/E-AC-3 直通。扩展**不做任何解码**，只提供自检面板。

## 安装（代码完成后）

**不上架任何商店，也不提供预编译安装包**，请自行构建：

```bash
pnpm install && pnpm build    # 产物在 .output/chrome-mv3/
```

`chrome://extensions/` → 开启开发者模式 → 加载已解压的扩展程序。理由见 [docs/guides/releasing.md](./docs/guides/releasing.md)。
