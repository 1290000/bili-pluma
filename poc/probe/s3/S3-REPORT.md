## 3. 布局计算（CSS 规则 + 实测）

`.acct-row` 规则（`sidebar.ts:458-472`）：
```css
display: flex; align-items: center; gap: 8px; padding: 7px 8px;
```

flex 项：`avatar(24, flex:0 0 auto)` + `.acct-main(flex:1 1 auto; min-width:0)` +
`.acct-tag(flex:0 0 auto)` + 胶囊 `(.acct-tag, flex:0 0 auto)`

```
面板宽               = 311.0
行内 padding 8×2     =  16.0   → 内容区 295.0
gap 8 × 3            =  24.0
avatar               =  24.0
────────────────────────────────
固定占用             =  48.0
剩余给 [main + VIP + 胶囊] = 295 - 48 = 247.0

VIP 标签实测         =  25.7
胶囊实测             =  67.0   （x268..340 总跨度）
────────────────────────────────
.acct-main 理论可用  = 247.0 - 25.7 - 67.0 = 154.3 CSS
```

### 4.1 昵称 / 副标题是否被截断 —— **两者都截断**

| `.acct-sub` | `仅取流 · 6 个月后到期`（13 字符） | `仅取流 · 6 个月...` | **❌ 截断** |

**截图肉眼可确认**（`acct.png`）：
```

副标题：仅取流 · 6 个月...
```

### 4.2 标签合计占比

```
VIP 标签(25.7) + 胶囊(67.0) = 92.7 CSS
占行内容区(295) 的 31.4%
占面板(311) 的 29.8%
```

**判据「⑥+⑦ 超过 ② 的一半」**：
- ② = `.acct-row.playback` 内容区宽 = **295 CSS**，一半 = **147.5**
- 92.7 **<** 147.5 → **未超过**

> ⚠️ **但这条判据（"超过一半"）没抓到真问题。**
> 真正的问题不是两个标签"占比过大"，而是 **`.acct-main` 只剩 154.3 CSS，
> 而昵称+副标题需要更多** —— 昵称 16 字符在 body 字号下约需 110–120 CSS，
> 加上副标题 13 字符约需 90–100 CSS，虽然它们上下排列各占一行，
> **但每行都要在 154 CSS 内放下** —— 昵称刚好卡线，副标题在副标题行的可用宽更窄。

## 5. 我的判断（回答 Lead 的三个问题）

### 5.1 胶囊要不要单独一行？—— **建议单独一行**

**理由（实测支撑）**：
- 胶囊占 **67 CSS**，是行内第二宽的固定元素（仅次于 avatar 的相对占用）
- 它 `flex:0 0 auto` **不收缩**，直接挤压 `.acct-main`
- 如果把胶囊移到单独一行（或与 VIP 标签同一行在账号名下方），
  **`.acct-main` 可多出 67 + 8(gap) = 75 CSS → 从 154.3 涨到 229 CSS**

**229 CSS 足够放下**：
- 昵称 `{{取流账号昵称}}`（16 字符，body 字号）≈ 110–120 CSS ✅
- 副标题 `仅取流 · 6 个月后到期`（13 字符，caption 字号）≈ 90–100 CSS ✅

### 5.2 副标题要不要缩短？—— **建议缩短**

即使胶囊移走，副标题仍可优化。当前 `仅取流 · 6 个月后到期` 有 **13 字符**。

**可选缩法**（按信息量排序）：
| 方案 | 文本 | 字符数 | 评价 |
| --- | --- | --- | --- |
| 现状 | `仅取流 · 6 个月后到期` | 13 | 最长 |
| 建议 A | `仅取流 · 6 个月` | 9 | 删"后到期"，保留关键信息 |
| 建议 B | `仅取流 · 到期 2027-05` | 15 | 更精确但更长 |

**推荐 A**：`后到期` 是冗余表述（"6 个月"本身已隐含期限）。

### 5.3 ⑧ 可用宽 vs 实际占用

| 项 | 值 |
| --- | --- |
| `.acct-row.playback` 内容区宽（②） | **295 CSS** |
| 实际被 ⑥⑦ 占用 | **92.7 CSS** |
| **留给 `.acct-main`（③）** | **154.3 CSS** |
| ③ 实际渲染宽（昵称段） | 80.7 CSS（截断处） |

## 6. 一个方法论发现（值得记录）

**面板的 `mode:'closed'` shadow 让所有 DOM 测量手段失效**：

| 手段 | 结果 |
| --- | --- |
| `document.querySelector('.acct-name')` | ❌ 拿不到（不在 light DOM） |
| `host.shadowRoot` | ❌ `undefined`（closed） |
| `bsk snapshot` 辅助功能树 | ✅ 有文本，**❌ 无尺寸** |
| `bsk observe --json` | ✅ 有文本，**❌ 无几何字段**（实测 `geometry fields: NONE`） |
| **截图 + 像素扫描** | ✅ **唯一能拿到内部尺寸的自动手段** |

**以后量面板尺寸，直接走截图 + Pillow**，不要再试 DOM 路径。
