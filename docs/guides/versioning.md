# 版本号规范

> 本文是版本号的**唯一权威位置**。发布流程见 [releasing.md](./releasing.md)。

---

**格式 `MAJOR.MINOR.PATCH`，当前 `1.0.0`。**

#### 先认清这个号在这里的作用

三段式版本的每个约定，前提都是**有下游在看**：商店靠它判断推不推更新、下游库靠它判断升级风险。
本项目三条硬约束把这两类下游都排除了——**不上架商店**（没有自动更新，Chrome 从不比较版本号）、
**zip 靠用户手动下载手动替换**（没有任何自动升级机制去比较版本号，见 [ADR 0018](../decisions/0018-ship-built-artifacts.md)）、
**没有依赖它的代码**。

所以版本号在这里只剩一个作用：**给人看，让人知道"这是哪一版、变化有多大"**。
判断标准因此不是"符不符合 semver 教科书"，而是"**第一眼读起来对不对**"。

#### 为什么是 1.0.0（以及当初为什么停在 0.9.0）

- **`1.0.0`** = 首个稳定版。番剧 / 国创 / 电影进了发行包，六条验收与 PGC 三条
  都在 1.0.0 的**构建产物**上真机重跑过（`v1-acceptance-checklist.md`）。
- **`0.9.0`** 当时的含义是「v1 范围已完整落地、通过六条验收，但明确还在观察期」。
  它是个**过渡号**：源码支持了 PGC，但下载包还没带上。用户能感知到"功能不全"，
  所以不能叫 1.0；又比"刚开了个头"完整得多，所以不是 0.0.x。
- 不用 `0.0.1`：读起来像未完成，而 `0.x` 在 semver 里表示"API 可能随时破坏"，
  这里没有接收方消费这个承诺，写成 0.0.x 只会显得没做完。
- 不用 `1.0.0-rc.1`：Chrome 的 `manifest.version` **只接受 1–4 段数字**，
  预发布后缀要另用 `version_name` 字段。为了一个没人读的后缀多一个字段，不值得。

> ⚠️ **0.9.0 → 1.0.0 是 MAJOR 跳**，因为用户能感知的行为变了：
> 番剧页从"完全不接管"变成"接管"，且页面脚本注入方式换了一代
> （旧包用 `web_accessible_resources`，新包用 `world: 'MAIN'`）。
> 所以 CHANGELOG 里必须有「需要用户操作」的说明 —— 重新加载扩展 + 确认 InPrivate 权限。

#### 分段怎么涨

| 段 | 什么时候 +1 | 例子 | CHANGELOG 里必须有 |
| --- | --- | --- | --- |
| `MAJOR` | **用户能感知的行为不兼容**，或白名单/协议破坏性变化 | 放弃某个已支持场景；`messages.ts` breaking change | **「需要用户操作」说明** |
| `MINOR` | 新增支持的场景或界面 | 支持番剧取流；新增设置项 | `### 新增` 至少一条 |
| `PATCH` | 修 bug、调文案 | 修续播失效（[ADR 0017](../decisions/0017-restore-primary-progress-in-playurl.md)） | `### 修复` 至少一条；纯文案可只写一行 |

**版本号与 CHANGELOG 是同一个动作的两半**：涨了号却写不出对应的变更条目，
说明这个号可能涨错了。写法见 [release-notes-template.md](./release-notes-template.md#怎么写-changelogmd-里的本版内容)。

#### 两个必须知道的事实

1. **`manifest.version` 每段上限 65535**（Chrome 规范）。**别把日期塞进任何一段** ——
   `20261026` 是 2689 万，超限，**装不上**。这排除了 `YYYYMMDD` 类方案。
   （`minimum_chrome_version: '120'` 这类形似版本号的值不受此限，但 `version` 本身受。）
2. **白名单修订号是另一个号**（`ROUTES_REVISION`，见 `src/shared/constants/routes.ts`）。
   它只在路径字符串或 `enabled` 开关变化时 +1，**与发布版本不同步**：
   改 UI 会升 PATCH 但修订号不动；补一条路径会升修订号但可以不发版。
   **两者不要混用**——用户报 bug 时问的是修订号（"我这份清单是哪一版"）。

同步更新两处，缺一不可：

- `wxt.config.ts` 的 `manifest.version`（WXT 没有独立的 `src/manifest.json`）
- `package.json` 的 `version`
