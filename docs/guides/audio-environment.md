# 音质环境：Hi-Res 与杜比全景声

> 2026-10-27 从根 `README.md` 移到这里。README 只留一行指向本文。
> 本文回答：**为什么我打开了 Hi-Res 视频却听不到 Hi-Res**。

---

## 一句话结论

| 音质 | 现状 | 需要你做什么 |
| --- | --- | --- |
| **Hi-Res（FLAC）** | 通常开箱可用 | 无 |
| **杜比全景声（EC-3）** | 要三条同时成立 | 见下方三条 |

扩展**只负责把音频流取下来，不做任何解码**。能不能放出声，取决于浏览器和系统。

## 杜比全景声：三条缺一不可

### 1. 装 Microsoft 的 EC-3 解码扩展

Store ID：`9nvjqjbdkn97`

没有它，浏览器认得这个音频格式，但没有解码器能把声音放出来。

**这一条诊断页能查**：设置页 →「诊断」→「音质环境」，看
`EC-3 解码（杜比全景声）` 那一行是否显示「解码器在」。

### 2. 浏览器启用 media foundation playback

地址栏进 `edge://flags` 或 `chrome://flags`，搜 `media foundation`，选 **Enabled**，重启浏览器。

**这一条诊断页也报不出来**（浏览器不暴露 flag 状态），只能自己核。

### 3. 系统音频设为空间音频 / E-AC-3 直通

Windows：声音设置 → 输出设备 → 属性 → 空间音频，或格式设为 Dolby Atmos。

**这一条只能你自己核**：浏览器读不到系统音频链路的配置。

## Hi-Res

**通常开箱可用。** Chrome / Edge 原生支持 FLAC，B站的 Hi-Res 走 FLAC in fMP4
（`audio/mp4; codecs=flac`），浏览器直接能解。

如果播放器显示 Hi-Res 但没声音，按顺序查：

1. 设置页「诊断」→「音质环境」第一行是「支持」吗？不支持就换新版浏览器
2. 音频输出设备是否被其他程序独占（某些声卡驱动有独占模式）
3. 是否用了蓝牙耳机——多数蓝牙编解码不支持无损码率，会静默降级

## 为什么扩展不做解码

技术上做不到，也没必要做：

- **不需要**：B站给的音频就是浏览器原生支持的格式（FLAC / EC-3 / AAC），
  扩展只负责换身份把流取下来
- **不该做**：在 MV3 扩展里软解音频意味着自己实现解码器，
  体积、性能、许可证都是负担，而收益为零

所以「能不能放」的判据永远是**浏览器 + 系统**，不是扩展。
