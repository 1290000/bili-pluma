Pluma {{VERSION}} 安装说明
========================================


一、解压
----------------------------------------

右键压缩包 → 全部解压。

会得到一个 pluma-{{VERSION}} 文件夹。


二、加载扩展（Edge / Chrome 一样）
----------------------------------------

1. 地址栏输入 edge://extensions
   （Chrome 是 chrome://extensions）

2. 打开左下角「开发者模式」

3. 点「加载解压缩的扩展」

4. 选中 pluma-{{VERSION}} 文件夹

   打开后第一层应该能看到 manifest.json、
   background.js、安装说明.txt。看到这三个就选对了。

   报「清单文件缺失」= 选错层级了，退回来重选
   那个 pluma-{{VERSION}} 文件夹。


三、开启 InPrivate 权限（必做）
----------------------------------------

扫码要在独立窗口里做，否则会顶掉你现在登录的
账号。没有这个权限，扫码窗口打不开。

1. 在 edge://extensions 找到 Pluma
   （Chrome 是 chrome://extensions）

2. 点「详细信息」

3. 打开「在 InPrivate 中允许」
   （Chrome 叫「在无痕模式下启用」）

4. 重新加载扩展

   跳过这步，点「扫码登录」会提示
   「需要在扩展详情页勾选」。


四、第一次使用
----------------------------------------

1. 点工具栏的 Pluma 图标

2. 点「扫码登录播放账号」，用大会员账号扫码
   （独立窗口，不影响你当前登录）

3. 打开任意 B站视频，画质菜单里会出现
   4K / 1080P60


五、本扩展不做什么
----------------------------------------

· 不绕过付费墙（会员番剧、电影仍需**你有该内容的权益**——
  用你登录的播放账号的权益，不是凭空解锁）

· 不伪装会员标识（界面显示你的真实状态）

· 不解锁地区限制


六、番剧 / 国创 / 电影
----------------------------------------

主账号只能试看的集数，会自动改用播放账号取流，直接看完整集。

免费集不接管，画质与原来一致——那是为了避免把观看进度记到播放账号上。

直播不支持。


七、出问题
----------------------------------------

画质没变    确认总开关是开的，并刷新过页面

凭据失效    重新扫码登录播放账号

其他        设置页 →「诊断」→ 导出诊断包
